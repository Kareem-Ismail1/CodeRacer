# CodeRacer
Hello! Welcome to CodeRacer! The ultimate way to both practice technical interview questions(LeetCode type questions) and have fun. 
The purpose of this is exactly that, provide more experience with LeetCode type questions in a 1v1, 2v2, or 4v4 format. The team that completes the question within the time limit first wins, if no one solves it, the winner is the one who got more test cases passed. 
This solves the problem of wanting to practice but not having any incentive, since it is fun, it will drive you to play, also the rank system also has incentive since people generally want to be ranked high. 
Compete against friends, or aim to be the best while learning!
